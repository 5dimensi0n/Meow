(or alternativwely visit the github page for it )https://kirbuke.itch.io/do-bugs-dream

The project was made using godot and the assets were all made by me in a traditional medium! Woohoo!! I used Krita (A free drawing software I reccomend) to touch up and isolate my traditional drawings.
This is my first time using godot so its bound to be a little unoptimized gulppp I tried my best! My main problem was getting the camera shake to work how i wanted to.
I had trouble connecting github to godot so i manually uploaded the files here.
I am planning on adding more levels to the game but school is kicking my butt right now so we'll have to see dot dot dot...

To make this project i didnt use as many video tutorials as i prefer forum posts but i heavily reccomend the official godot forum for any problems you face!
I went into this project a bit blind as to how godot works and hoped my prior knowledge of python and general game design would carry me (which it didnt)
